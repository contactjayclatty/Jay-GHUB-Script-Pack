BEFORE YOU RUN IT

A quick check.

  • Windows, with Logitech G HUB installed and opened at least once.
  • Use the Windows account that normally runs G HUB.
  • Windows PowerShell and .NET Framework are required; Python and a .NET SDK are not.
  • Fully quit G HUB before installing or uninstalling.
