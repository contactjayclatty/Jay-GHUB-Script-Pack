01 / GET STARTED

Three steps.
Then make it yours.

Already have scripts? Matching names are skipped. Your existing tuning stays put.

  1. 01

    Close G HUB.

    Open G HUB at least once on this Windows account, then fully quit it from the system tray.

  2. 02

    Choose your operators.

    Run the installer. Search the roster, check the operators you want, then choose Install selected. A snapshot backs up your existing scripts first.

  3. 03

    Select. Configure. Test.

    Reopen G HUB and select your script in the profile's Scripting editor. Set your vertical and horizontal strengths, then test your setup.

STARTS AT ZERO

Every template starts at vertical 0 / horizontal 0. Operator names organize the pack; these are neutral templates, not pre-calibrated weapon profiles. Installation alone produces no scripted movement.

04 / GOOD TO KNOW

Before you install.

Full setup & recovery guide ↗
Will it replace my existing scripts?

No. Matching operator names and recognized aliases are skipped. Your current scripts are backed up before new templates are added. Installing this pack does not activate a script for your profile.

Where does it install?

Under %LOCALAPPDATA%\LGHUB\scripts for the Windows account running the installer. It finds that account's folder automatically. Administrator access is not normally required.

How do I uninstall?

Quit G HUB and choose Uninstall pack in the installer. This checks all scripts installed by the pack, regardless of the checklist. Only unchanged owned scripts are removed. Edited scripts, unrelated files and backups remain.

What settings should I change?

Start with RcCustomStrength and HorizontalStrength. Leave advanced timings and controls alone unless you understand them. Calibration depends on your weapon, attachments, sensitivity and DPI.

Where can I report an issue?

Use GitHub Issues for reproducible bugs or Discussions for setup help. Include your Windows and G HUB versions, selected operators and the installer result.
