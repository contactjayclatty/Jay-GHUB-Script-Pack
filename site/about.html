04 / ABOUT THE PROJECT

Built by Jay.
Open to you.

A small Windows utility for keeping a named collection of G HUB Lua templates easy to install and easy to inspect.

WHY THIS EXISTS

Less folder work.
More control over your setup.

The pack brings 78 operator templates into one installer. You choose the lineup; the installer handles separate entries, snapshots and ownership records.

All distributed scripts start with neutral strengths. Operator names help organize your collection. Calibration stays with the person using the script.

The code is public under the MIT license, so you can inspect it, modify it and redistribute it with the required notice.
