01 / GET STARTED

Install the pack.

Already have scripts? Matching names are skipped. Your existing tuning stays put.

  1. 01

    Close G HUB.

    Open G HUB at least once on this Windows account, then fully quit it from the system tray.

  2. 02

    Choose your operators.

    Run the installer. Search the roster, check the operators you want, then choose Install selected. A snapshot backs up your existing scripts first.

  3. 03

    Select. Configure. Test.

    Reopen G HUB and select your script in the profile's Scripting editor. Set your vertical and horizontal strengths, then test your setup.

02 / CONFIGURE

Start with the strengths.

Select the installed operator script in G HUB's Scripting editor for your intended profile. Installing a template does not select or activate it.

RcCustomStrength = 0

Downward movement per vertical step.

HorizontalStrength = 0

Negative for left, positive for right.

Both start at zero. Change one value at a time and test your weapon, attachments, sensitivity and DPI. There is no universal strength setting.

Keep advanced controls steady.

The pack retains vertical frequency 2, horizontal frequency 4 and delay 7. Caps Lock is the default toggle. With the template enabled, its firing logic checks both aim and fire inputs and resets its counters for each burst. The script preview shows the exact controls.

03 / BACKUPS

Your starting point is saved.

Before installation, the current scripts folder is copied into a dated snapshot. New operator templates use separate UUID folders. Existing names and known aliases are skipped.

%LOCALAPPDATA%\LGHUB\
  scripts\
    <operator UUID>\
      config.json
      script.lua
  script-pack-installs\
    siege-operator-lua-pack-v1\
      installed.json
      backups\
        <timestamp>\scripts\

Restore a script

  1. Fully quit G HUB.
  2. Open the appropriate snapshot's scripts directory.
  3. Keep a separate copy of any newer tuning you want to preserve.
  4. Copy only the operator UUID folders you want back into %LOCALAPPDATA%\LGHUB\scripts.
  5. Reopen G HUB and check the selected script and profile.

04 / UNINSTALL

Remove the pack.
Keep your edits.

Fully quit G HUB, run the installer, and choose Uninstall pack. This checks all scripts installed by the pack, regardless of the current checklist.

Only unchanged owned files are removed. Modified scripts, unrelated folders and backup snapshots remain. You can remove a preserved script manually in G HUB when you no longer need it.

05 / TROUBLESHOOT

Check these first.

The installer says G HUB is running.

Quit G HUB from its system tray icon. If necessary, close lghub and lghub_agent in Task Manager, then retry.

An operator was skipped.

A matching name or alias already exists and was preserved. Check that script in G HUB; the installer does not overwrite existing calibration.

The script produces no movement.

Both strengths start at zero. Check the selected profile and script, Caps Lock state, aim/fire inputs and your configured strengths.

Script names do not appear.

Restart G HUB and check the intended profile's Scripting editor. If names are still missing, report the G HUB version and exact installer result.

Windows blocks the executable.

The release is unsigned and organizational policies may block it. Check the published checksum and scan report. Do not disable security software; report any detection with the filename and hash.
